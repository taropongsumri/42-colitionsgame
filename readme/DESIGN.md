# Coalition Backrooms: design decisions

เกม 2.5D pixel art สำหรับ pisciner 42 Bangkok ธีม backroom แข่งกัน 3 บ้าน
เอกสารนี้สรุปทุกอย่างที่ตกลงกันระหว่างคุยออกแบบ ใช้เป็นแหล่งอ้างอิงหลักตอนสร้าง

## ผู้เล่นและการเชื่อมต่อ
- มี 3 บ้าน บ้านละ 8–9 คน **แต่ละบ้านใช้ client เครื่องเดียว** (1 บ้าน = 1 ตัวละคร) รวมทั้งหมด 3 client
- quest จริงเกิดนอกเกม (สตาฟจัดเอง) เกมมีหน้าที่แค่แสดง quest, รับรหัสหรือคำตอบ แล้วตรวจที่ server
- ขั้นตอน join
  1. client เปิด URL แล้วเห็นรหัสเครื่อง 4 ตัว
  2. admin กำหนดว่าเครื่องนั้นเป็นบ้านไหน แล้วกด Accept
  3. server เก็บ session token ไว้ใน cookie
- รีเฟรชหรือเน็ตหลุด กลับเข้าบ้าน ห้อง และ HP เดิมได้อัตโนมัติ
- admin Kick หรือย้าย session ไปเครื่องอื่นได้ 1 บ้านมี client ที่ใช้งานได้ทีละเครื่องเดียว
- **หลุดระหว่างสู้บอส: เลือดบอสรีเซ็ตกลับเต็ม**

## แมพ
- แมพเป็นห้องเล็กต่อกันเป็นสาย **ห้องละ 1 คำถาม** ตอบถูกแล้วประตูห้องถัดไปถึงเปิด (fog of war)
- ทุกบ้านใช้ layout เดียวกัน แต่ **คำถามคนละข้อในทุกห้อง** (`questionIds: { h1, h2, h3 }`)
- ห้องเรียนเขียนโค้ด backroom มีโต๊ะกลมแบ่ง 4 ส่วนแบบพิซซ่าวางกระจาย ปลั๊กไฟหลักอยู่ในรูตรงกลางโต๊ะ
  - ปลั๊กเรืองแสง = โต๊ะตัวจริง เดินไปแล้วกด `E` เปิด terminal ขึ้นมาตอบ
  - ตอบผิด ปลั๊กช็อตเป็นประกายไฟ และล็อก terminal 10 วินาที (ปรับได้ใน config)
  - โต๊ะหลอกโต๊ะหนึ่งซ่อน hint ไว้ ถ้าคำถามข้อนั้นมี `hint`
- เงาของบ้านอื่นที่อยู่ห้องหมายเลขเดียวกันกับเรา แสดงเป็นเงาโปร่งแสงตามสีบ้าน

## ห้องบอส
- วาร์ปไปอีกโลก ธีมตามสตาฟแต่ละคน (รายละเอียดผู้ใช้จะส่งมาทีหลัง)
- **คำถามเดียวต่อบอส** เป็นภารกิจยาว เช่นวิ่ง 1 กม. ไปเอาคำตอบกลับมา
- **ช่วงรอ (monkey typing):** พิมพ์คำภาษาอังกฤษง่าย ๆ จาก word pool ของบอส
  - คำที่พิมพ์ถูกเติมโล่ บอสตีเป็นจังหวะและกินโล่ โล่หมดแล้วเสีย HP
  - แต่ละคำลดเลือดบอสนิดหน่อย แต่ไม่ต่ำกว่า 10%
  - พิมพ์ผิดตัวไหนจะติดอยู่ตัวนั้นจนกว่าจะแก้
- **ตอบแบบ Audition:**
  1. กด `Tab` เข้าโหมดโจมตี ระหว่างนี้ไม่มีโล่
  2. พิมพ์แบบไม่เห็นอะไร จอโชว์แค่ `■` ไม่มี feedback
  3. กด `Enter` ให้ server ตรวจ
  4. ถ้าถูก เล่น combo ตามจังหวะ BPM ตัวอักษรเด้งขึ้นทีละตัว พร้อมท่าที่ผูกกับประเภทตัวอักษร (สระ / พยัญชนะ / ตัวเลข / สัญลักษณ์) จบด้วยท่าไม้ตายที่เก็บ 10% สุดท้าย
  5. ถ้าผิด ช่องแตกกระจาย บอสสวนกลับ แล้วกลับไปช่วงรอ
- **HP หมด:** สตัน 30 วินาที จอ glitch บอสฟื้นเลือดบางส่วน
  - หักคะแนนบ้าน (ค่าเริ่มต้น 50)
  - ล็อกช่องส่งคำตอบนานขึ้นเรื่อย ๆ 30 → 60 → 90 วินาที ...
  - ระยะล็อกสะสมรีเซ็ตเมื่อล้มบอสตัวนั้นได้

## คะแนน
- จำกัดเวลาเล่น ค่าเริ่มต้น 90 นาที แก้ได้ใน config
- ผ่านห้องได้คะแนน ผ่านบอสได้คะแนนก้อนใหญ่
- **โบนัสตามลำดับที่ผ่าน:** ที่ 1 +50%, ที่ 2 +20%, ที่ 3 +0%
- คะแนนติดลบได้
- scoreboard โชว์คะแนน, ห้องปัจจุบัน, HP ระหว่างสู้บอส และเวลาที่เหลือ

## ตัวละครประจำบ้าน (ล็อกตามบ้าน)
| บ้าน | สัตว์ | สี | ท่าบอส |
|---|---|---|---|
| h1 | แมงป่อง | ส้ม-เหลือง | ต่อยด้วยหาง, ก้ามหนีบ, พิษ |
| h2 | ช้าง | เทา | กระทืบพื้น, ฟาดงวง, พ่นน้ำ |
| h3 | ปลาหมึก | ม่วง | หนวดฟาด, พ่นหมึก, วังวน |
- ตัวผู้เล่นเป็น **คนใส่ชุดมาสคอต** แบบฮู้ดคลุมหัวมีหูหรือหางของสัตว์ประจำบ้าน
- มี **สัตว์ตัวจิ๋วเดินตาม** เป็นสัตว์เลี้ยง ตอน combo ในห้องบอส สัตว์เลี้ยงเป็นตัวออกท่าคู่กับผู้เล่น
- เงาของบ้านอื่นแสดงเป็นรูปร่างตัวละครของบ้านนั้นแบบโปร่งแสง

## โหมด Spectator (สำหรับ tutor และสตาฟ)
- เปิดที่ `/spectate` ต้องใส่ spectator key ที่ตั้งไว้ใน `config.ts` ไม่ต้องรอ admin approve และไม่จำกัดจำนวนคน
- ผู้ชมเป็น **ดวงไฟลอยได้อิสระ** ทะลุกำแพงได้ ไม่โดน fog of war บิน (`WASD`) ไปดูห้องไหนก็ได้ และเปิดดูโลกบอสของแต่ละบ้านได้
- **เปิดปิดการมองเห็นได้:** ผู้ชมกดสลับเองได้ว่าจะให้ผู้เล่นเห็นดวงไฟของตัวเองหรือไม่ ส่วน admin มีสวิตช์รวมที่บังคับซ่อนดวงไฟทุกดวงได้
- ผู้ชมโต้ตอบกับเกมไม่ได้เลย ทั้งตอบคำถามและเปิด hint

## Admin (GUI)
- lobby: เห็นเครื่องที่รอ, กำหนดบ้าน, Accept, Kick, ย้ายเครื่อง
- ปุ่มควบคุม
  - Pause / Resume
  - +/- คะแนน พร้อมเหตุผล
  - Force unlock ห้อง
  - ส่งข้อความขึ้นจอ
  - แก้คำตอบสด
  - ต่อเวลาหรือตัดเวลา
- จัดการคลังคำถาม (ID), dungeon (ลำดับห้อง), บอส และ live config ทั้งหมด

## Stack
- Bun + SvelteKit (`svelte-adapter-bun`) ใช้ WebSocket ใน process เดียวกัน deploy บน Linux Ubuntu
- client 2.5D pixel art วาดบน canvas
  - asset จาก skill **pxl**
  - เอฟเฟกต์สกิลจาก **pixelfx** (`vendor/pixelfx`)
- **config 2 ชั้น**
  - `config.ts`: secrets (Mongo URI, Discord webhook, รหัสผ่าน admin, พอร์ต) และค่าเริ่มต้นทั้งหมด
  - live config: อยู่ใน Mongo แก้จากหน้า admin มีผลทันที มีปุ่ม Reset to defaults
  - secrets ไม่ส่งไปที่หน้าเว็บ
- **MongoDB แยกเป็น 4 database**
  - `coalition_content`: questions, dungeons, bosses
  - `coalition_config`: live config พร้อมประวัติการแก้
  - `coalition_game`: session, บ้าน, ความคืบหน้า, คะแนน
  - `coalition_logs`: checkpoint, ทุกครั้งที่ตอบ, สตัน, admin audit, การส่ง Discord
- **Discord webhook** ยิงเฉพาะ event สำคัญ ไม่ยิงตำแหน่งการเดิน (rate limit ประมาณ 30 ข้อความต่อนาที)
  - เริ่มเกม
  - ผ่านห้อง
  - เข้าบอส
  - สตัน
  - ล้มบอส
  - ปุ่มที่ admin กด
  - จบเกม
- คำตอบตรวจที่ server เท่านั้น ไม่ส่งไปที่ client

## ยังเปิดอยู่
- ธีมและ word pool ของบอสแต่ละตัว (รอข้อมูลสตาฟ)
- จำนวนห้องจริงและเนื้อหาคำถาม
